# 📝 Blog-Web

A modern, responsive **blogging platform** built with React and Tailwind CSS.  
It allows users to create, read, update, and delete blog posts, with route protection and authentication.

---

## 🚀 Features

- ✍️ **Create & Manage Blogs** – Add, edit, and delete blog posts.  
- 🔐 **Authentication** – User login & signup with protected routes.  
- 👤 **User Dashboard** – Manage personal blogs and profile.  
- 📱 **Responsive Design** – Works across desktop and mobile.  
- ⚡ **Fast & Optimized** – Built with modern technologies.  

---

## 🛠️ Tech Stack

- **Frontend:** React  
- **Styling:** Tailwind CSS  
- **Build Tool:** Vite  
- **Routing:** React Router (with `ProtectedRoute.jsx`)  
- **Version Control:** Git & GitHub  


Blog-Web/
